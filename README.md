# ZORIVA Website

Bilingual (English / Bahasa Indonesia) corporate landing page for ZORIVA.

## Brand foundation
- Tagline: **Intelligence for a Better Tomorrow.**
- Essence: Smart. Human-Centric. Impactful.
- Personality: Innovative, Approachable, Professional, Global.
- Primary colors: Midnight Navy `#080F20`, Zoriva Blue `#3978FF`, Zoriva Purple `#8B5CF6`, Zoriva Cyan `#35D5E8`, Cloud `#F7F9FC`.
- Typography: Manrope (headings), DM Sans (body).
- Logo: geometric Z mark with blue-purple-cyan gradient and ZORIVA wordmark.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Import this repository into Vercel and use the Next.js preset. No environment variables are required for the landing page.

## Before public launch
1. Replace `hello@zoriva.com` with the confirmed business email if needed.
2. Confirm product URLs and add links to each product card.
3. Confirm trademark/domain availability before investing in final commercial identity.
4. Review bilingual copy and add privacy/legal pages when lead forms or analytics are introduced.
